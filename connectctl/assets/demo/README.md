# BKKT local demo

This directory is generated by `bkkt demo init`.

It contains a small local Kafka-compatible stack for trying BKKT without any
company-specific infrastructure:

- Redpanda Kafka API and Schema Registry API;
- Kafka Connect worker;
- Redpanda Console;
- sample `connectctl.yaml`;
- sample Kafka topic manifest.

## Start

```bash
docker compose up -d
```

## Inspect

```bash
bkkt --config connectctl.yaml config clusters --env dev
bkkt --config connectctl.yaml kafka brokers health --env dev --cluster local
bkkt --config connectctl.yaml kafka topics plan --env dev --cluster local --file kafka/topics/dev/demo.yaml
bkkt --config connectctl.yaml kafka topics apply --env dev --cluster local --file kafka/topics/dev/demo.yaml --dry-run
bkkt --config connectctl.yaml schema subjects list --env dev --cluster local
```

Redpanda Console: http://localhost:8080

Schema Registry: http://localhost:8081

Kafka Connect REST: http://localhost:8083
